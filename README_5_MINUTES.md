# Tau Scaling in 5 Minutes

## Purpose

Tau Scaling Runtime evaluates post-Moore scaling claims by forcing them through a declared evidence path.

## Runtime chain

```text
claim -> source boundary -> claim card -> workload profile -> tau vector
-> baseline/candidate manifests -> LogicFolding gate -> edge/surface model
-> energy/thermal/PDN/PVT gates -> Monte Carlo stress test
-> TSEK class -> evidence package
```

## Strong claim rule

A strong Tau Scaling claim needs:

- source boundary
- metric definition
- baseline
- method disclosure
- workload declaration
- tau vector
- LogicFolding survivability if relevant
- energy / thermal / PDN / PVT gates
- yield / method disclosure
- evidence package
- no overclaim

## Non-claim lock

Roadmap coherence is not validation.  
Simulation is not silicon evidence.  
Density equivalence is not node equivalence.  
Local path win is not full-chip win.
