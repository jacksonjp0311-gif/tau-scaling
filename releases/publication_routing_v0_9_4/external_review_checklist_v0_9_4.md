# External Review Checklist v0.9.4

| ID | Blocking | Check | Required response |
|---|---:|---|---|
| R1 | True | Does the manuscript clearly state that Tau Scaling is not validated by this artifact? | Yes; non-claim lock must remain visible in abstract, limitations, and conclusion. |
| R2 | True | Does every source-populated claim remain separated from primary-source confirmation? | Yes; source-populated is not source-validated. |
| R3 | True | Does the artifact distinguish public secondary reporting from first-party evidence? | Yes; public reports must not be promoted to primary validation. |
| R4 | True | Are claim ledger, source ledger, evidence table, gap matrix, and release checks reproducible? | Yes; commands and paths must be listed. |
| R5 | True | Does the paper avoid semiconductor performance, product, investment, or process-node claims? | Yes; scope remains evidence-governance. |
| R6 | True | Are limitations explicit enough for an external reviewer to reject overclaiming? | Yes; limitations table and ethics/non-claim statement must be present. |
| R7 | False | Is the publication route appropriate for a repository-based artifact? | Technical note or GitHub release first; preprint only after external review. |

Boundary: review checklist completion is not claim validation.
