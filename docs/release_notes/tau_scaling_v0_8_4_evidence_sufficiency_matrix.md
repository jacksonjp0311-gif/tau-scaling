# TAU-SCALING-SA v0.8.4 - Evidence Sufficiency Matrix

## Purpose

Define what evidence is sufficient to preserve, promote, downgrade, or reject each public Tau claim.

## Added

- Evidence sufficiency matrix generator.
- Claim-level evidence matrices.
- Missing-gate summary and promotion/downgrade rules.
- Evidence sufficiency visual.
- README research section and roadmap update.

## Boundary

Evidence sufficiency matrices define promotion conditions only. They do not promote claims, mutate thresholds, validate silicon, validate products, prove benchmark superiority, or establish a universal Tau Scaling law.
