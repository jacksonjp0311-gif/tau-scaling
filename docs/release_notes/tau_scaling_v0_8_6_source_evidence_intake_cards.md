# TAU-SCALING-SA v0.8.6 - Source Evidence Intake Cards

## Purpose

Convert public source provenance into concrete source-intake cards with required source fields.

## Added

- Source evidence intake card generator.
- Per-claim intake cards.
- Source intake summary report.
- Source intake visual.
- README source-intake section.
- Release lineage and next-version update.

## Boundary

Source evidence intake cards collect source requirements only. They do not promote claims, validate silicon, validate products, prove benchmark superiority, or establish a universal Tau Scaling law.
