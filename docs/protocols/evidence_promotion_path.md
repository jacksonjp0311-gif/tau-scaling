# Evidence Promotion Path Protocol

Generated: 2026-05-26T05:30:39-04:00

## Rule

Promotion is evidence-driven, not prose-driven.

A claim can only move to a stronger class when new evidence fields are disclosed and the classifier accepts them under declared gates.

## Required Surfaces

- source boundary
- workload profile
- tau vector
- baseline manifest
- candidate manifest
- LogicFolding survivability
- edge/surface ratio
- gamma_tau_ETP
- PVT / PDN / closure checks
- yield method and yield result
- independent validation status
- downgrade ledger

## Forbidden Moves

- Do not mark simulation as silicon validation.
- Do not mark yield disclosure as independent validation.
- Do not classify roadmap coherence as validation.
- Do not convert a local demo to a product claim.
- Do not loosen gates to make a dashboard look better.
